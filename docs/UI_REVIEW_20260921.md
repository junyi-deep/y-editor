## 已修复

### P0 — 文档更多菜单点击外部不收起（用户报告）

根因不是缺少外部点击处理，而是 `DropdownMenu :modal="false"`（`EditorShell.vue` 两处）。非模态下 Reka 的运行时无法收敛：打开弹层后 Node 的定时器阶段停摆，关闭动作永远落不了地，菜单就停在那里。实测最小复现——同样的菜单 `modal` 取默认值时 1.7 s 内开合干净，取 `false` 时测试进程挂死。

修复：删除两处 `:modal="false"`，交给默认模态行为。真实浏览器验证：点击文档区 → 菜单关闭且焦点回到触发按钮；`Escape` 同样关闭。

### P1 — 危险色不达 AA

`--y-danger` 在浅色面板上只有 4.47:1（AA 要求 4.5:1），深色恰好卡在 4.50。错误文案是必须读到的内容，不能踩线。

`#c8443c → #bc3a33`（5.13:1）、`#e06c62 → #e5796f`（5.05:1）。

### P1 — 标题栏过高且空

40px 的带子里只有一个 12px 的居中文件名，两侧全空。修复为三层：

- 高度 40 → 36px；`--y-titlebar-h` 同时供侧栏页签与 AI 面板表头使用，三条 chrome 行的度量不再各说各话。
- 交通灯重新居中（`y: 18 → 12`，同步 `tauri.conf.json` 与 `windows.rs`），此前 40px 高度下偏下 4px。
- 带子里补上工作空间文件夹名（11px、muted、超长省略），标题仍按 macOS 惯例绝对居中。

### P1 — AI 面板空状态与输入区

- 空状态原本顶对齐，下方留出约 250px 死区；改为在会话区垂直居中（`justify-content: safe center`，窗口过矮时安全退化为顶部对齐，不会被裁掉）。
- 标题 22px → 15px；340px 宽的侧栏里 22px 抢戏。
- 起步按钮去掉右侧远隔 250px 的箭头——它读起来像「跳转」而不是「插入提示词」。
- token 用量行在无用量时隐藏，空状态下不再占一行零。
- 输入区：选项（当前文档 / 思考）从输入框上方下移到页脚行，与发送按钮同排；textarea 最小高度 88 → 64px。
- `.ai-input .ai-actions button { min-width: 48px }` 会波及移入该容器的复选框按钮，把 13px 的方框拉成 48×13 的长条；收窄为直接子选择器。

### P1 — 命令面板快捷键显示

面板显示原始 `Mod+q`，而菜单栏显示 `⌘Q`。新增 `shortcutLabel()`（`src/command-palette/registry.ts`），两处共用，现统一为 `⌘Q` / `⌘⇧N`。存储格式仍是 `Mod+Shift+n`——那是编辑器绑定与快捷键录制框使用的拼写。

### P2 — 面板把分类冒充成快捷键

无快捷键的命令在同一个键帽样式里显示分类（如「文件」）。已改为只在真有快捷键时渲染键帽。

### P1 — 查找栏

- 查询框 `flex: 1` 且无上限，在宽窗口里被拉成约 1570px；改为 260px 上限。
- `↑ ↓ ▸ ▾` 是 Unicode 字形冒充图标（项目已确立单一 Phosphor Bold 图标系统，此前替换的正是 ⋯ ☷ ↻ ⛶ B I S ↗ ×，查找栏漏了）；改为 `up` / `down` 图标与旋转的 `chevron` 折叠指示。
- 原生 checkbox 与 input 换成 owned `Checkbox` / `Input`；两个复选框补 `aria-label`（`区分大小写` / `正则表达式`），不再让 `.*` 当无障碍名。

### P1 — 六处原生 checkbox 残留，PATCHES.md 的声明不成立

`PATCHES.md` 写着「文字字段已跨设置 / AI / 查找 / 面板迁移」，实际 `src/` 里仍有 8 处原生 `<input type="checkbox">`：查找栏 2 处、资源面板 3 处、命令面板 1 处、资源对话框 1 处、AI 面板 1 处、AI 差异块 1 处。查找栏随上面的返工一并改掉，其余 6 处本轮也全部换成 owned `Checkbox`。

两处是**数组型复选框组**，owned `Checkbox` 是布尔语义，不能直接 `v-model`：资源面板的「选择要导入的引用」与 AI 面板差异块的「应用此处修改」。改为 `:model-value` + 显式 `toggleCandidate` / `toggleHunk` 维护索引数组，行为不变。

`tests/ui-controls.test.ts` 的源码扫描相应加上 `type="checkbox"` 禁令，让这条约束可被测试，而不是靠文档自觉。

### P1 — 错误红有两个来源

`.error-banner` / `.conflict-banner` / `.form-message` / `.inline-error` / `.palette-error` 用的是硬编码 `#b45534`，而 AI 面板的错误走 `var(--y-danger)`。同一个应用里错误文案出现两种红，且硬编码那个不随主题走。三处 `#b45534` 全部归到 `var(--y-danger)`。

## 记录未改（需要你定夺或不成立）

- **P2 预设链接色**：Typora 正文链接 `#4183c4` 对白底 3.99:1、Atom One `#4078f2` 对 `#fafafa` 3.88:1，均低于正文 4.5:1。修它必须改预设调色板，而 ADR-0008 明确「保留可选主题」，因此只记录不动。可选择：把正文链接单独做 12% 加深（保留 chrome 的预设原色），或接受与 Typora 一致的现状。
- **P3 检测器告警**：`styles.css:246` 的 `border-left: 4px` 经核对为文档块引用（blockquote）的左侧律，用中性 `--y-border` 结构令牌，不是卡片色条；判定为检测器误报，已按最小范围忽略（`side-tab=*` 仅限 `src/app/styles.css`，写在 `.impeccable/config.json`，该目录在 `.gitignore` 内，属本机配置）。`side-tab` 规则不提供按值忽略的提取器，因此只能到文件粒度——这也会挡掉该文件里将来真正的色条，若之后在 `styles.css` 里新增卡片样式需要留意。
- **P2 jsdom 承载不了 Reka 弹层**：打开门户弹层后 jsdom 定时器阶段停摆，`flushPromises` / `vi.waitFor` 永不返回，测试即使跑完函数体也会被判超时。因此「外部点击关闭」与「焦点归还」这两项真实行为不在 jsdom 里测，改由 `pnpm ui:check` 在真实浏览器断言。相关背景写在 `tests/settle.ts`。
- **P3 模型服务页签与其标题同名**：子页签「模型服务」之下又有一个「模型服务」大标题，其余分类的标题都带额外信息（通用 → 文件与保存），只有它重合。
