# TASK-20260920 — 表格交互、Mermaid 编辑、AI 面板与 UI 框架

需求：`dev-prompts/开发提示词_20260920.md`。架构决策：ADR-0007（Tailwind + shadcn-vue），沿用 ADR-0006 的窗口与编辑器边界。

Triage 方法：五个维度并行诊断（表格 / Mermaid / AI 面板 / shadcn-vue 集成 / macOS 视觉方向），每条结论再经一次对抗性复核。11 条确认为真实缺陷（含根因与 file:line），16 条为设计方案，1 条被否决。

## 表格操作优化

- [x] 右键单元格时「表格」二级菜单默认展开（`interactions.ts`，`submenu(menu, "表格")` 后加 `open`）。
- [x] 修复无法拖动行列：6 px 边框带是唯一的拖拽热区——现在**表头整格**是列把手，单元格左边缘仍是行把手，两者都补了光标提示。原地松开仍走 `source === target` 守卫（点击而非重排），表头里编辑文字仍从双击进入。
- [x] 修复多选后右键丢失选区：右键（含 macOS ctrl+click）时若当前是 `CellSelection` 则 `preventDefault`，浏览器不再移动插入点，ProseMirror 不会把 `CellSelection` 读回成 `TextSelection`。

## Mermaid 图操作优化

- [x] 去除「完成编辑」按钮；点击块外任意位置自动退出并重新渲染（`document` 捕获阶段 `pointerdown`，判定对象是 `.y-code-block` 而非编辑时隐藏的 `.mermaid-render`）。
- [x] 补 `Escape` 退出与 `Mod-Enter` 退出，否则去掉按钮后键盘用户被困在编辑态。
- [x] 编辑态代码高亮：`@codemirror/language-data` 无 mermaid 条目，新增 `codemirror-lang-mermaid@0.5.0`，动态导入（该包把全部图解析器打进一个模块，只有文档里真有图时才加载）。

## AI 交互面板优化

- [x] 修复输入框无法点击聚焦：`textarea` 的 `:disabled` 绑定了默认 `false` 的 `ai.enabled`，且面板内没有可开启它的控件；现在输入框始终可用，发送按钮按 `ai.busy || !prompt.trim()` 禁用，从面板选择连接即视为启用。
- [x] 去除上传按钮，只通过 `@` 引用：删除 `.image-attach` 与 `input[type=file]`；`@` 列表新增图片项（面板内独立调用 `list_files {allFiles:true}` 过滤图片扩展名，绝不翻转侧栏共用的 `workspace.allFiles`），选中后经既有的 `image_read` 读取为待发送图片。同一提交内完成——否则删掉上传按钮会让图片彻底无法引用。
- [x] 面板上方连接与模型设置：连接下拉支持切换、面板内新增「＋ 新增连接…」直接打开偏好设置 AI 分类；模型输入回写所选连接的 profile，不再在切换连接时被静默还原。
- [x] `@` / `/` 候选列表此前被 `.ai-input > div`（优先级高于 `.ai-suggestions`）压成一行，收窄为 `.ai-input > .ai-actions`。

## 重大 UI 框架重构

- [x] ADR-0007：引入 Tailwind 4.3.3 + shadcn-vue，`--y-*` 仍是唯一真源。
- [x] Tailwind 分层导入（仅 theme + utilities，**不引入 preflight**）：preflight 会清掉文档列表符号、把行内图片变成块级、重写边框，而这些都是本项目从未声明、依赖 UA 默认的写作界面基础。补一条 `border: 0 solid` 兜底。
- [x] 令牌桥接：`@theme inline` + 在 `:root` 声明令牌（组件门户会挂到 `body`，必须能解析到令牌），`--y-accent` → `--primary`（shadcn 的 `--accent` 是悬停面，映射到 `--y-hover`），并把颜色镜像到 `documentElement`。
- [x] 暗色变体跟随应用（`@custom-variant dark` → `[data-theme="dark"]`），不是跟随系统偏好。
- [x] 首个迁移证明：外观 / 预置主题两个下拉改为 shadcn `Select`，`tests/settings-select.test.ts` 验证真实渲染与取值。
- [x] 复制组件补丁：`SelectContent` 去掉动画类（不引入 `tw-animate-css`，AppKit 菜单不做淡入）并把 `z-50` 换成本项目的 z 令牌（`z-50` 低于 `--y-z-modal: 200`，弹窗内下拉会被遮罩盖住）。记录在 `PATCHES.md`。
- [x] 原生 macOS 窗口：真实红绿灯（`decorations: true` + `titleBarStyle: Overlay` + `trafficLightPosition`，主窗口与新窗口都设）替换手绘的 − □ ×；窗口内菜单栏只在浏览器预览里保留。
- [x] 单一图标系统：Lucide（1.75 描边）替换全部 Unicode 占位符（⋯ ☷ ↻ ⛶ B I S ↗ × 以及 ☐/☑——后者还是死代码，Milkdown 渲染真实 checkbox 且从不设置 `data-checked`）。
- [x] 控件度量与状态：状态栏四份互相矛盾的定义合并为一份；焦点环只留一处（透明 outline + accent 光晕，兼顾 Windows 高对比度）；列表选中按 AppKit 规则（窗口是 key 时用 accent，非 key 时用中性）。
- [x] 代码用系统等宽栈；滚动条不覆盖 macOS 原生 overlay 行为。
- [ ] 仍待迁移的 5 处原生 `<select>`：正文字体、资源面板筛选、AI 连接行、模型服务传输方式、资源对话框。
- [ ] macOS 视觉结果未目视验收：本机 `tauri-driver` 报「not supported on this platform」，无自动化驱动可截图。

## 交付后复核（20 项确认 / 3 项否决）

复核又发现并修掉了本轮引入或此前未覆盖的问题：

- Mermaid 退出编辑后 `activeCode` 仍指向已隐藏的 CodeMirror，之后任何工具栏/面板插入都会写进代码围栏（文本损坏）——`exit()` 现在一并清空该指针。
- AI 面板输入框此前 `:disabled` 使其不可用；本轮放开后暴露出 IME 缺陷：提交候选词的 Enter 会把未组合完成的文本发出去，改为 `isComposing` 时直接返回（命令面板同样处理）。
- 切换连接时把 `ai.session` 置空会孤立流式响应，导致 busy 卡死且停止按钮失效——已移除该行。
- `@` 图片列表只在挂载/换根时刷新，刚粘贴的截图不会出现——改为跟随文件列表变化。
- 元素级 reset 是**无层** CSS，会压过 Tailwind 的 `@layer utilities`（迁移过来的 Select 触发器因此没有边框）：reset 移入 `@layer base`，并修正 `text-sm`/`h-9` 在 13px 根字号下解析成 11.4px/29.25px 的问题。
- 状态栏 `min-height: 30px` 仍在钳制新的 26px 令牌；`scrollbar-width: thin` 会覆盖 macOS 原生 overlay 滚动条（注释却声称不动它）——两处都已修正。
- 新窗口不会继承配置里的红绿灯位置，`windows.rs` 现在显式设置。
- 图片附件的体积上限与 `ai_send` 的 base64 上限对齐，避免发送后才失败。
- `.agents/` 加入 `.gitignore`，Tailwind 不再扫描缓存的技能文档（此前约 8.6% 的产物 CSS 来自那里）。
