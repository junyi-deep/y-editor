## 2026-09-20 复查与设计重构

勾选项经九维审计逐条对照代码复核（23 项确认、3 项被否决），修正了勾选状态掩盖的真实缺陷：

- 表格：单元格上/左边缘 6 px 内的按下会启动行列重排，按住后原地松开因此会重建整张表、丢掉单元格选区并多出一步撤销 —— 即「单击拖动可以选择多个」在该区域内不可用。`moveTable` 现在把落在原行/原列的移动视为点击。
- 表格：插入/删除行列会把字面 `<br />` 写进用户的 Markdown（Milkdown 的 `remarkPreserveEmptyLine` 序列化空段落所致）；该 remark 的两半都已从 commonmark preset 中移除，空单元格现在序列化为空单元格。
- 多窗口：第二个窗口的过期快照会覆盖共享配置记录。`save_settings` 改为接收键补丁，`settings::merge_patch` 合并到进程持有的记录，前端只上报自己真正改动的键；最近记录始终由数据库持有。
- 快捷帮助：面板承诺可搜索功能，却丢弃所有无快捷键的命令；搜索时现在归入「无快捷键」分组。快捷键搜索两侧统一归一化，`cmd s`、`ctrl+shift+p`、`⌘S` 均可命中 `Mod+S`。
- 侧边栏：底部操作栏移除后新建只剩右键一条路；新增 `workspace.create` 与 `file.newFile` / `file.newFolder` 命令，命令面板、快捷键面板与可重映射快捷键据此复用同一入口。
- Mermaid：「源码展开时隐藏图表」的判据依赖 Milkdown 不会渲染的 Vditor 类名，因此形同虚设；改为由 node view 提供的 `editing` 钩子，主题切换不再遮住已打开的源码。

设计重构（redesign-existing-projects）：类型/圆角/阴影/背景遮罩/过渡/z-index 全部改为设计令牌；三个模态标题统一为同一字号；AI 面板与快捷键面板共用同一头尾结构；`.settings-body nav` 收窄为直接子元素，去掉两处 `!important`；编辑器标题恢复真实层级（原本 H3 与 H4 同尺寸、H5/H6 小于正文）；引用条与行内链接改用主题令牌；文档「更多」菜单按内容定宽（原固定 156 px，每行约 44 px 空白）；文件树、AI 历史与设置表格补齐空状态；字数/面板计数/用量改用等宽数字。

删除约 120 行不可能匹配任何已渲染元素的 CSS、`interactions.ts` 中不可达的原生拖拽监听、`mermaid.ts` 的 Vditor DOM 兜底、`src/editor/adapter/vditor-patches/`、空的 `patches/` 与未使用的 `highlight.js` 依赖。
