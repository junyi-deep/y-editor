# ADR 0005: SQLite data and editor extension boundary

Accepted 2026-09-19 for TASK-20260918, superseding credential-store and movable configuration choices in prior ADRs by explicit user request.

All durable application metadata (settings, credentials, workspaces, resource registrations, indexes and conversations) lives in executable-sibling `.yeditor/data.db`. SQLite records use parameterized statements, atomic upserts, WAL and a busy timeout. Unix directory/file permissions are 0700/0600. Credentials are not returned to Vue; provider requests and Pi environment construction remain native. No legacy JSON import is required. Resource files use `.yeditor/res/{type}`; knowledge/repository sources remain referenced folders. Temporary Pi protocol manifests contain environment variable references, never secret literals.

Vditor assessment: current IR adapter already owns source preservation, canonical Markdown, selection, table mutation, diagram rendering and native image hooks. The requested contextual menus, table reordering, inline code presentation and diagram split view can be implemented at these existing boundaries. Replacing the editor would risk source normalization, undo/selection and Typora parity without resolving a missing fundamental API. Retain Vditor IR, isolate all integration in src/editor/adapter, and verify editing/undo behavior. Reconsider only if those invariants cannot be maintained.

Schema 6 adds opacity, attachment-folder/paste choices using defaulted fields for older serialized settings values. The storage-location change deliberately does not import old JSON files. Session image bytes live in `res/chat-images`; SQL stores their identifiers. Provider model retrieval uses the saved native credential and refuses redirects, preventing cross-host authorization forwarding. New workspaces snapshot global resource defaults; host MCP/knowledge access consults workspace flags.

Code highlighting uses CSS Custom Highlight ranges, not added span nodes. Browser editing regression exposed Vditor source truncation when inline token spans were inserted; the accepted range approach leaves source DOM and selections intact. Markdown chat rendering disables raw HTML and remote image fetching, throttles stream updates, and routes links through the bounded native link command. Native opacity uses transparent Tauri windows (macOS private API feature, suitable for direct distribution rather than Mac App Store packaging).
