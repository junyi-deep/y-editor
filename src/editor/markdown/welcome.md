# 让想法，落在纸上。

欢迎来到 **y-editor**，你的本地 Markdown 写作空间。

从一个念头开始，写下你的下一篇文章、项目笔记，或尚未成形的想法。内容与排版在同一处发生，让注意力回到文字本身。

## 为专注而设计

这里使用即时渲染：当你写下 Markdown，格式自然呈现。将光标移入文本，即可继续编辑标记。

> 好的工具退后一步，让你的思考向前一步。

你可以试着编辑这段文字，使用 **粗体**、*斜体*，或者创建一个属于自己的列表。
